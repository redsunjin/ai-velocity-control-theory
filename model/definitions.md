# Definitions — v0.1

이 문서는 AVCT의 변수와 용어를 고정하기 위한 기준표다. 명칭은 이론보다 먼저 바뀔 수 있지만, 의미가 바뀔 때는 반드시 CHANGELOG에 기록한다.

## A — Parallel Agent Count
동일한 분석 시간 창 안에서 실제 작업을 수행할 수 있는 병렬 에이전트 수.

주의: 생성된 에이전트 인스턴스 수가 아니라 **작업에 기여하는 실행 주체 수**를 측정해야 한다.

## λ — Per-Agent Execution Rate
에이전트 1개가 단위 시간당 생성하는 후보 행동 또는 작업 완료율.

단위 예: actions/minute, tasks/hour.

## T — Relevant Time Window
실행 우위가 의미를 가지는 시간 창.

예:
- 경쟁자가 대응하기 전까지의 시간
- 시장 상태가 바뀌기 전까지의 시간
- 한 배포/운영 사이클
- 인간 승인 SLA

`T`는 임의의 관찰기간이 아니라 **경쟁 또는 운영상 의미가 있는 반응 창**이어야 한다.

## S — Coordination Efficiency
병렬 실행이 중복·충돌 없이 동일한 목표에 기여하는 정도.

개념 범위: `0 ≤ S ≤ 1`을 기본으로 두되, 실제 측정 방식은 연구 설계에서 정의한다.

`S`는 고정 상수가 아니다. 다음 요인의 영향을 받을 수 있다.

- 에이전트 수 `A`
- 작업 간 결합도
- 공유 메모리/컨텍스트 품질
- 스케줄링 및 오케스트레이션
- 통신 지연
- 역할 분해 품질

## R — Execution Reliability
후보 행동 중 목표·정책·품질 조건을 만족하는 유효 행동의 비율 또는 확률.

`R`은 단순한 LLM 정답률이 아니다. 실제 실행 환경에서는 다음을 포함할 수 있다.

- 사실 정확성
- 정책 준수
- 작업 완료성
- 부작용 부재
- 재현 가능성
- 실행 후 회수 가능성

## N_eff(T) — Effective Action Mass
시간 창 `T` 안에서 실제로 목표에 기여하는 유효 실행량.

`Mass`는 물리량이 아니라 분석적 은유다. 단위는 행동/작업 수다.

## α — Contextual Effect Coefficient
유효 실행량을 경쟁 또는 조직 효과로 변환하는 환경 계수.

시장 구조, 업무 유형, 실행 가치, 희소성, 고객 반응성 등의 영향을 받는다.

## β — Effect Elasticity / Amplification Exponent
`N_eff` 증가가 `P_AI` 증가로 변환되는 비선형성의 정도.

AVCT는 `β=2`를 전제하지 않는다.

## P_AI — Competitive / Organizational Effect
AI 유효 실행량이 만들어내는 결과 효과를 표현하기 위한 추상 변수.

연구마다 측정값을 명시해야 한다.

예:
- 매출/전환 변화
- 실험 학습량
- 대응 시간 단축
- 발견된 결함 수
- 시장 점유 변화
- 업무 처리량

서로 다른 결과변수를 하나의 `P_AI` 숫자로 합산하는 것은 피한다.

## q_control — Control-Requiring Fraction
AI의 유효/후보 행동 중 별도의 검토·승인·차단·감사가 필요한 비율.

위험 기반 라우팅을 잘 설계할수록 이 비율은 낮아질 수 있다.

## Λ_control — Control Demand Arrival Rate
단위 시간당 통제 시스템으로 유입되는 통제 필요 작업의 평균 도착률.

단위 예: reviews/minute, approvals/hour.

## μ_control — Control Processing Capacity
조직이 단위 시간당 적절한 품질로 처리할 수 있는 통제 작업의 처리율.

포함 가능한 요소:
- 인간 검토자
- 정책 엔진
- 자동 검증
- 위험 분류
- 회수/롤백 구조

단, 자동 검증을 포함하는 경우 인간 통제 용량과 조직 전체 통제 용량을 문서에서 구분한다.

## K — Control Saturation Ratio

`K = Λ_control / μ_control`

통제 요구가 처리 능력에 얼마나 가까운지를 나타내는 운영 지표.

`K`는 queue utilization과 유사한 구조를 차용한다. 따라서 수학적 비율 자체의 신규성을 주장하지 않고, **AI 에이전트 조직의 실행-통제 동역학에 적용하는 개념 프레임**으로 다룬다.

## Control Debt
즉시 처리되지 않았지만 향후 검토·정정·책임 추적이 필요한 실행의 누적 부담.

단순 backlog와 달리, 이미 외부 효과를 발생시킨 행동의 사후 통제 비용까지 포함할 수 있다.

## Reversibility
잘못된 AI 행동을 제한된 비용과 시간 안에 원상복구하거나 영향을 격리할 수 있는 정도.

AVCT에서는 동일한 `K`라도 reversibility가 높으면 위험이 낮아질 수 있다는 조절 변수를 향후 검토한다.
